TREND DETECTIVE — DATA SOURCES, APIs, AND MODELS
NASA Space Apps Challenge submission inventory
Updated: 15 November 2026

PURPOSE
-------

This is the source-of-truth inventory for the submitted application. Each entry states exactly how it is used.
“Used at runtime” means the deployed backend can request it. “Bundled” means a derived asset is shipped with the
front end. “Reference only” means it is cited in explanations but never treated as application data.

The project deliberately keeps measured climate data, forecast data, news context, map geometry, and AI explanations
separate. No optional third-party weather or AI result is included in a NASA POWER trend calculation.

1. EARTH-SYSTEM DATA USED AT RUNTIME
------------------------------------

NASA POWER — Prediction Of Worldwide Energy Resources
  Official API documentation: https://power.larc.nasa.gov/docs/services/api/
  Runtime endpoint:            https://power.larc.nasa.gov/api/temporal/monthly/point
  Provider: NASA Langley Research Center (LaRC) POWER Project.
  Authentication: none.
  Used for: monthly point time series and derived annual values for 19 variables:
    T2M, T2M_MAX, T2M_MIN, T2M_RANGE, TS;
    PRECTOTCORR, RH2M, QV2M, TQV;
    EVLAND, GWETROOT, GWETTOP, PRECSNOLAND;
    ALLSKY_SFC_SW_DWN, CLRSKY_SFC_SW_DWN, ALLSKY_SFC_LW_DWN, CLOUD_AMT;
    WS2M, PS.
  Application use: place trends, comparison, regional scan, world survey, monthly frames, and forecasts.
  Credit: “Data obtained from the NASA Langley Research Center (LaRC) POWER Project funded through the NASA Earth
          Science/Applied Science Program.”

NASA GISS GISTEMP v4 — global and zonal surface-temperature anomalies
  Dataset information: https://data.giss.nasa.gov/gistemp/
  Global CSV requested: https://data.giss.nasa.gov/gistemp/tabledata_v4/GLB.Ts+dSST.csv
  Zonal CSV requested:  https://data.giss.nasa.gov/gistemp/tabledata_v4/ZonAnn.Ts+dSST.csv
  Authentication: none.
  Used for: global temperature vital sign and the independent temperature cross-check.

NOAA Global Monitoring Laboratory — Mauna Loa monthly CO2
  Dataset landing page: https://gml.noaa.gov/ccgg/trends/
  CSV requested:        https://gml.noaa.gov/webdata/ccgg/trends/co2/co2_mm_mlo.csv
  Authentication: none.
  Used for: atmospheric CO2 planet vital.

NOAA@NSIDC Sea Ice Index, Version 4 (G02135)
  Dataset page: https://nsidc.org/data/g02135/versions/4
  Data archive: https://noaadata.apps.nsidc.org/NOAA/G02135/
  DOI: https://doi.org/10.7265/a98x-0f50
  Authentication: none for the files requested by this application.
  Used for: Arctic and Antarctic monthly sea-ice extent planet vitals.
  Note: the app attempts Version 4 files and legacy-compatible file names to make the stream resilient to a version
        transition. The current source record is Version 4.

NOAA Climate Prediction Center (CPC) — Oceanic Niño Index and North Atlantic Oscillation
  CPC climate-index directory: https://www.cpc.ncep.noaa.gov/data/indices/
  ONI file requested:           https://www.cpc.ncep.noaa.gov/data/indices/oni.ascii.txt
  NAO file requested:           https://www.cpc.ncep.noaa.gov/products/precip/CWlink/pna/norm.nao.monthly.b5001.current.ascii.table
  Authentication: none.
  Used for: climate-rhythm context, detrended correlation checks, and optional ENSO-adjusted local trends.
  Interpretation: correlation is not presented as causation.

NOAA National Centers for Environmental Information (NCEI) — ERSSTv5 PDO index
  ERSSTv5 product page: https://www.ncei.noaa.gov/products/extended-reconstructed-sst
  File requested:        https://www.ncei.noaa.gov/pub/data/cmb/ersst/v5/index/ersst.v5.pdo.dat
  Authentication: none.
  Used for: Pacific Decadal Oscillation climate-rhythm context.

2. BUNDLED DERIVED DATA AND MAP MATERIAL
----------------------------------------

Coarse global climate preview assets
  Source: NASA POWER monthly point API (link above).
  Files: frontend/public/coarse/T2M.json, PRECTOTCORR.json, CLOUD_AMT.json, manifest.json.
  Construction: 15-degree point grid, 264 locations, monthly values from 2023-01 to 2025-12; values are quantised
                for a light-weight visual overview.
  Used for: immediate, approximate global temperature/rainfall/cloud patterns while detailed local data loads.
  Not used for: point values, statistics, p-values, trend conclusions, or forecast claims.
  Rebuild script: tools/coarse_preview/build.py.

Natural Earth map data through world-atlas
  Natural Earth: https://www.naturalearthdata.com/
  world-atlas package: https://www.npmjs.com/package/world-atlas
  topojson-client package: https://www.npmjs.com/package/topojson-client
  d3-geo package: https://www.npmjs.com/package/d3-geo
  Used for: land and border geometry on the canvas globe. The map data are not a climate data source.
  Licence/status: Natural Earth data are public domain.

Project-maintained city/place catalogue
  File: backend/app/places.py and front-end capital/location utilities.
  Used for: sample places, saved-location validation, and locations for contextual news markers.
  Nature: curated approximate place centroids; it is not an authoritative boundary or geocoding service.

3. OPTIONAL OPERATIONAL CONTEXT (SEPARATE FROM TREND ANALYSIS)
----------------------------------------------------------------

Meteomatics Weather API
  Product/API page: https://www.meteomatics.com/en/weather-api/
  Runtime API base: https://api.meteomatics.com/
  Authentication: HTTP Basic authentication, supplied server-side only through METEOMATICS_USERNAME and
                  METEOMATICS_PASSWORD.
  Used for: optional hourly live-weather panel at a selected location, via GET /api/live-weather.
  Not used for: historical trend statistics, p-values, NASA POWER values, or the coarse global preview.
  Failure behaviour: returns an explicit “unconfigured” or “unavailable” state and leaves core analysis working.

GDELT 2.0 DOC API
  Project: https://www.gdeltproject.org/
  Runtime endpoint: https://api.gdeltproject.org/api/v2/doc/doc
  Authentication: none for the default adapter.
  Used for: optional current news context around saved locations and a fixed global rotation of locations.
  Safeguards: environmental-topic filtering, URL/title de-duplication, cache, stale-on-error response, and deterministic
              green/amber/red labels. The labels are editorial triage, not emergency-alert levels.
  Not used for: data analysis, statistical significance, or proof of a scientific claim.

4. AI, STATISTICS, AND FORECAST MODELS
---------------------------------------

OpenAI Responses API (optional)
  Documentation: https://platform.openai.com/docs/guides/responses
  Web-search tool guide: https://platform.openai.com/docs/guides/tools-web-search
  Runtime endpoint default: https://api.openai.com/v1/responses
  Authentication: OPENAI_API_KEY on the backend only.
  Model: selected by the owner via OPENAI_EXPLANATION_MODEL; no OpenAI model name is hard-coded in this repository.
  Used for: optional “Why might this be happening?” explanation after a server-verified case is computed.
  Safeguards: NASA/NOAA/NSIDC and other science-domain allow-list, source validation, limited tool calls, output
              validation, rate limiting, caching, and a sourced curated fallback when unavailable.
  Not used for: calculating any statistics, forecasts, p-values, or severity labels.

Internal statistical methods (no external AI/ML service)
  Implemented in: backend/app/stats.py, analysis.py, forecast.py, monthly.py, ml.py, archetypes.py, morans.py.
  Used for: Theil-Sen slope and confidence interval; Mann-Kendall trend test; OLS regression test; autocorrelation
            adjustment; Benjamini-Hochberg correction; Pettitt change-point test; emergence analysis; spatial Moran’s I;
            short-horizon forecast selection and backtesting; ridge-regression, clustering, and similarity features.
  Audit: docs/STATS_AUDIT.md.
  Important: these are explanatory statistical tools and short-horizon forecasts, not formal climate projections.

Curated “Why?” fallback sources
  IPCC AR6 Working Group I: https://www.ipcc.ch/report/ar6/wg1/
  Global Carbon Project: https://globalcarbonproject.org/
  AMAP: https://www.amap.no/
  Additional peer-reviewed URLs are embedded and source-validated in backend/app/explanations.py.
  Used only when explaining possible mechanisms; never fetched as primary time-series data by the app.
