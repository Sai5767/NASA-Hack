TREND DETECTIVE - DATA SOURCES, API CALLS AND AI MODELS

Final V2 inventory, written by the integration agent on 2026-11-15 from the code in this folder (backend/app, frontend/src,
frontend/package.json, backend/.env.example). It lists what the code actually calls or bundles, not a wish list.

Categories used below:
  ACTIVELY USED        the default build calls or bundles it with no key or account.
  OPTIONAL/CONFIGURED  the code is implemented, but it only runs when the owner sets server-side settings; without them the
                       app shows an intentional "not configured" state.
  PLANNED, NOT BUILT   discussed for later; no code calls it. Do not claim it as a feature.
  REFERENCE ONLY       cited or linked for reading; never fetched as data.

Note: the final browser walkthrough (live UI labels on every screen) has not been done yet. The UI labels below are the
ones written in the code.

====================================================================
1. ACTIVELY USED - EARTH-SCIENCE AND CLIMATE DATA
====================================================================

NASA POWER (monthly point API)
  Provider: NASA Langley Research Center (LaRC) POWER Project
  Endpoint family: https://power.larc.nasa.gov/api/temporal/monthly/point (server-side only, backend/app/nasa_power.py)
  Kind: reanalysis/model blended with satellite and ground observations (not a street-level measurement)
  Purpose: every local trend (/api/trend, /api/sweep, /api/grid, /api/duel), the world sample-site survey (/api/world,
    /api/ledger, /api/archetypes), the local 1x1-3x3 monthly grid on the globe (/api/monthly-frames) and the inputs to
    both internal forecasts (/api/forecast, /api/monthly-forecast).
  UI label: "Observed/reanalysis, NASA POWER"; the globe field carries the local-grid caveat ("coarse local NASA POWER
    grid", not a global map); world dots say "Sample sites, not a complete global map".
  Credit shown: "NASA Langley Research Center (LaRC) POWER Project, funded through the NASA Earth Science/Applied Science
    Program".

NASA GISS GISTEMP v4
  Endpoint family: data.giss.nasa.gov/gistemp/tabledata_v4 (GLB.Ts, ZonAnn.Ts), backend/app/streams.py
  Kind: observed (station + ocean analysis)
  Purpose: Explore > Vitals global and latitude-band temperature anomalies. UI: "NASA GISS GISTEMP".

NOAA Global Monitoring Laboratory - Mauna Loa CO2
  Endpoint family: gml.noaa.gov/webdata/ccgg/trends/co2 (co2_mm_mlo.csv)
  Kind: observed
  Purpose: Explore > Vitals CO2 series. UI: "NOAA GML".

NSIDC Sea Ice Index (G02135)
  Endpoint family: noaadata.apps.nsidc.org/NOAA/G02135
  Kind: observed (satellite passive microwave)
  Purpose: Explore > Vitals Arctic and Antarctic sea-ice extent. UI: "NSIDC Sea Ice Index".

NOAA Climate Prediction Center and NCEI climate indices
  Endpoint families: cpc.ncep.noaa.gov (ONI, NAO tables), ncei.noaa.gov (ERSST v5 PDO index)
  Kind: observed indices
  Purpose: ENSO/PDO/NAO context in Vitals and the ENSO-adjusted check in the case file. UI: "NOAA CPC and NCEI".

2. ACTIVELY USED - NEWS CONTEXT (keyless default)
====================================================================

GDELT DOC 2.0 API
  Endpoint family: https://api.gdeltproject.org/api/v2/doc/doc (server-side, backend/app/news.py GdeltNewsProvider)
  Kind: news context (not scientific evidence)
  Capital-city popups (not a service): frontend/src/lib/capitals.js is a hand-written list of the 193 UN member states'
    capitals with approximate positions (static geography, bundled, no request). The popups show derived details and a few
    fixed facts only.
  When it runs: automatically on Main once onboarding is finished (never before), for the user's saved places first and
    then the capitals (frontend/src/lib/capitalNews.js): batches of at most five, one batch at a time, eight seconds
    apart, main countries first, at most 24 batches (120 capitals) per visit, a 60 second back-off when rate-limited and a
    stop after three failed batches in a row, through the same cached and rate-limited /api/news flow. Only the fixed
    capital list is ever requested, never arbitrary coordinates. NEWS_PROVIDER=disabled turns it off.
  UI label: every item says "news context, not scientific evidence"; green/amber/red is an attention label from
    transparent keyword rules, not an official warning; items whose host is not on the verified-publisher list
    (publisher_verified: false) are shown as "Unverified news context".

3. OPTIONAL / CONFIGURED ONLY
====================================================================

Meteomatics Weather API (live point weather)
  Endpoint family: https://api.meteomatics.com/{validdatetime}/{parameters}/{location}/json (server-side only)
  Kind: operational weather forecast/nowcast, 1-72 hours, one point
  Parameters: t_2m:C, precip_1h:mm, total_cloud_cover:p, wind_speed_10m:ms
  Settings: METEOMATICS_USERNAME, METEOMATICS_PASSWORD (+ optional METEOMATICS_BASE_URL, METEOMATICS_TIMEOUT_SECONDS,
    METEOMATICS_CACHE_TTL_SECONDS, METEOMATICS_RATE_LIMIT_MAX, METEOMATICS_RATE_LIMIT_WINDOW_SECONDS,
    METEOMATICS_GLOBAL_RATE_LIMIT_MAX, METEOMATICS_GLOBAL_RATE_LIMIT_WINDOW_SECONDS)
  Without credentials: /api/live-weather returns status "unconfigured" and the card says so.
  UI label: Meteomatics source, valid/fetch time, stale state and "not NASA trend data"; it is separate from NASA POWER
    history and from the app's own monthly forecast.
  Status: real-account path tested only against in-memory fakes; the owner's one-call smoke test is still pending.

OpenAI Responses API with the web_search tool (manual "Why might this be happening?")
  Endpoint family: OpenAI Responses API (server-side only, backend/app/explanations.py), tool "web_search" with
    filters.allowed_domains = the science allow-list
  Kind: AI-generated possible explanations with citations (context, not proof)
  When it runs: only when the user presses the Why button after a completed analysis; answers cached 24 h.
  Settings: OPENAI_API_KEY and OPENAI_EXPLANATION_MODEL (both required; no model name is hard-coded) + optional
    OPENAI_BASE_URL, OPENAI_TIMEOUT_SECONDS, OPENAI_WEB_SEARCH, OPENAI_WEB_SEARCH_CONTEXT_SIZE, OPENAI_MAX_TOOL_CALLS,
    OPENAI_MAX_OUTPUT_TOKENS, EXPLANATION_CACHE_TTL_SECONDS, EXPLANATION_RATE_LIMIT_MAX,
    EXPLANATION_RATE_LIMIT_WINDOW_SECONDS
  Without key or model: status "no_key" with the curated literature fallback, shown as such.
  UI label: "These are possible explanations, not proof that one cause created this local trend."
  Runtime model: none chosen yet (owner step). Status: tested only against fakes; owner smoke test pending.

Configurable JSON news feed
  NEWS_PROVIDER=json_feed (or azure/custom) with NEWS_API_URL and NEWS_API_KEY. Not configured by default; any provider
  needs a terms review. Optional: NEWS_TIMEOUT_SECONDS, NEWS_CACHE_TTL_SECONDS.

4. INTERNAL ANALYSIS AND FORECAST MODELS (run in the backend, no external AI)
====================================================================

Trend statistics (backend/app/stats.py, analysis.py): Theil-Sen slope and interval, Mann-Kendall test, OLS t-test,
  serial-correlation adjustment, Benjamini-Hochberg false-discovery control, Pettitt change point, emergence year and the
  evidence verdict (evidence_trace). Audited in docs/STATS_AUDIT.md. The browser never computes these.
Annual forecast lab (backend/app/forecast.py, ml.py): naive baselines, trend models, ridge regression and an ensemble,
  backtested; replays are labelled "illustration, in-sample".
Monthly forecast (backend/app/monthly.py): 1-3 months for T2M, PRECTOTCORR and CLOUD_AMT on the local grid; seasonal-naive,
  harmonic/damped-trend and regularised autoregressive candidates; frames appear only when eligible is true.
  UI label: "Forecast - not observed data", hatched, after an observed/forecast divider.
Archetypes (backend/app/archetypes.py): clustering of sample-site fingerprints.
Spatial pattern (backend/app/morans.py): Moran's I for Explore > Scan.

Coarse preview asset (static, bundled; added 15 Nov 2026 by the Globe agent)
==========================================================================================
What: frontend/public/coarse/T2M.json (38,056 bytes), PRECTOTCORR.json (34,965 bytes), CLOUD_AMT.json (38,743 bytes),
      manifest.json (1,115 bytes). Served from the page's own origin; no request to NASA when a variable is chosen.
Source: NASA POWER monthly point API, https://power.larc.nasa.gov/api/temporal/monthly/point
        (community RE, parameters T2M, PRECTOTCORR, CLOUD_AMT in one request per point).
Grid: 15 degrees, latitudes -75..75, longitudes -180..165 (264 points); months 2023-01 .. 2025-12 (36 months).
Retrieved: 2026-11-15 (0 failed points). Built by tools/coarse_preview/build.py (httpx, at most 4 concurrent
        requests, retries with backoff). Values quantised to integers (scale 0.1 / 0.01 / 0.1).
Licence/terms: NASA POWER data are freely available; acknowledge "Data obtained from the NASA Langley Research
        Center (LaRC) POWER Project funded through the NASA Earth Science/Applied Science Program."
Use: the globe's "Coarse global preview · approximate pattern" layer only (soft, low-resolution orientation).
        Never used for trends, p-values, forecasts, exact values or local conclusions. Detailed local data
        (/api/monthly-frames) always draws on top. Rebuild: python tools/coarse_preview/build.py
Base Earth: procedural (Natural Earth 110m land/borders via world-atlas, public domain); no imagery is bundled.
